進階會員

讓買家及其 AI 代理，都能確認您的品牌值得信任。

進階會員提供依照品信會品牌可信度基線評估進行的全面、獨立信任評審。評分達 80% 或以上的品牌，將獲發 CGBB Verified Trusted 信任憑證及徽章。

  • 以證據評審基線評估全部 15 項指標
  • 評分達 80% 可獲 Verified Trusted 信任憑證及徽章
  • 年度複審，確保評分保持最新
在會員帳戶升級先取得免費級別

年費：315 美元。會員可在會員帳戶中升級。全面信任評審將於品信會標準公佈後（2026年11月底）開始。

如何運作

升級

進階會員最少為期一年。

信任評審

品信會評審您的品牌及相關證據。

評分達 80%

未達標將收到改進建議報告。

發佈

將憑證放上網站，並展示徽章。

條件：持有有效進階會員資格，基線評分最少 80%，證據支持度至少為中，且沒有未解決的重大風險。升級本身並不保證獲發憑證。

憑證檔案內容
一份簡短、經簽署、機器可讀並可公開核實的紀錄。示意如下：
{
  "standard": "CGBB Trust Standard 1.0",
  "issuer": "Council for Global Brand Building",
  "organisation": "Example Co. Ltd.",
  "domain": "example.com",
  "trust_score": 86,
  "dimensions": { "...": "seven dimension scores" },
  "issued": "2027-01-15",
  "valid_until": "2028-01-15",
  "verify": "https://api.cgbb.org/verify/example.com",
  "signature": "..."
}
「信任已核實」徽章

已核實品牌可在發佈信任憑證的同時展示徽章。徽章連結至品牌的即時紀錄，訪客一按即可核實。通過核實後將提供淺色及深色版本。

請以下列代碼將徽章加入網站，並把 yourdomain.com 換成您的網域。訪客點擊徽章，即可在 cgbb.org/verify 查看您的即時紀錄。

常見問題

升級會員是否保證獲發 Verified Trusted 信任憑證？

不保證。檔案僅發予持有有效進階會員資格，並在全面信任評審中取得最少 80% 評分的機構。

其他人能否複製我們的信任憑證並放到自己的網站上？

檔案本身是公開的，因此可以被複製，但複製品毫無作用。每份檔案都綁定其獲發的指定網域，放在其他網站上會即時無法通過核實。

如品牌會員資格失效或評分下降，會怎樣？

品信會會在登記冊中撤銷有關紀錄。即使品牌網站上的檔案看似不變，也將無法通過核實。檔案亦設有效期，並於每次年度複審後續發。
