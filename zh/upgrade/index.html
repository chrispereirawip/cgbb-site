會員 · 進階

讓客戶，以及為他們工作的AI代理，都能確認您的品牌值得信任。

越來越多採購方透過AI助手篩選供應商、合作夥伴和品牌。進階會員可獲得依照品信會標準進行的全面、獨立信任評審。評分達80%或以上的品牌，將獲發經品信會驗證的 trust.json 檔案：一份可供機器讀取的信任資質紀錄，AI購物及採購代理可直接從您的網站讀取。

升級會員所有會員方案

會員權益

  • 全面信任評審。依據全球品牌公信力指數的七個維度，以經核實的證據進行全面評估，並由品信會評審小組審核，遠較免費的初步信任診斷深入。
  • 經品信會驗證的trust.json檔案，適用於評分達80%或以上的品牌，並於api.cgbb.org提供公開驗證紀錄。
  • 年度複審，確保評分及檔案保持最新。
  • 優先聯絡秘書處，並享有品信會活動會員價格。

如何取得trust.json

  1. 1升級會員進階會員最少為期一年。
  2. 2完成全面信任評審升級生效後，品信會將對您的品牌及相關證據進行全面評審。
  3. 3評分達80%或以上達標品牌將獲發經簽署的trust.json檔案；未達標品牌將收到改進建議報告，並可再次申請評審。
  4. 4於網站發佈將檔案置於 yourdomain.com/.well-known/trust.json。任何AI代理、平台或採購方均可對照品信會公開紀錄進行核實。
須同時符合兩項條件

trust.json僅發予持有有效進階會員資格，並在全面信任評審中取得最少80%評分的機構。升級會員本身並不保證獲發檔案。檔案在會員資格有效、且品牌於年度複審中維持80%或以上評分期間有效。

檔案內容

一份簡短、經簽署、機器可讀並可公開核實的紀錄。示意如下：

{
  "standard": "CGBB Trust Standard 1.0",
  "issuer": "Council for Global Brand Building",
  "organisation": "Example Co. Ltd.",
  "domain": "example.com",
  "trust_score": 86,
  "dimensions": { "...": "seven dimension scores" },
  "issued": "2027-01-15",
  "valid_until": "2028-01-15",
  "verify": "https://api.cgbb.org/verify/example.com",
  "signature": "..."
}

「信任已驗證」徽章

獲驗證品牌可在發佈trust.json檔案的同時，展示品信會「信任已驗證」徽章。徽章連結至品牌的即時紀錄，訪客一按即可核實。

通過驗證後將提供淺色及深色版本。

常見問題

其他人能否複製我們的trust.json並放到自己的網站上？

檔案本身是公開的，因此可以被複製，但複製品毫無作用。每份檔案都綁定其獲發的指定網域，放在其他網站上會即時無法通過核實。

檔案中的評分或日期能否被更改？

不能。品信會以只有品信會持有的私鑰為每份檔案進行數碼簽署，並在cgbb.org公佈相應的公鑰。即使只更改一個字元，例如評分或有效期，簽署亦會失效。

AI代理及採購方如何確認檔案真偽？

每份檔案均連結至api.cgbb.org上的紀錄。代理會直接查核該即時紀錄，因此品牌當下是否獲驗證，以品信會登記冊而非檔案本身為準。

如品牌會員資格失效或評分下降，會怎樣？

品信會會在登記冊中撤銷有關紀錄。即使品牌網站上的檔案看似不變，也將無法通過核實。檔案亦設有效期，並於每次年度複審後續發。

如網站在未獲驗證的情況下展示徽章或檔案，怎麼辦？

任何人都可以在品信會公開登記冊中查詢該網域。聲稱已獲驗證卻沒有有效紀錄的品牌，一經查核即會被揭穿，品信會亦可對濫用其標誌的行為採取行動。

升級會員是否保證獲發trust.json？

不保證。檔案僅發予持有有效進階會員資格，並在全面信任評審中取得最少80%評分的機構。

費用

進階會員年費將於稍後公佈。會員現可提出升級申請，秘書處將以電郵確認費用及後續安排。
