1適用範圍

本基線評估的物件是品牌，即品牌背後的機構及其留下的公開記錄。適用於任何規模、行業和市場的企業。

它衡量的是信任是否有據可查。它不檢測產品、不審計賬目，也不提供法律意見；評估結果不構成對企業產品、質量、財務狀況、合規或行為的認證、審計或保證。

2原則

看證據，不看說法

每項指標都依據具體的核查項評定。「不確定」視為沒有證據。

同樣的證據，同樣的結果

規則固定並按版本管理，任何人都不能人為調整結果。

風險不會被平均掉

尚未解決的重大風險會限制總分，無論其他部分表現多好。

「資訊不足」也是一種結果

證據不足以判斷時，基線會如實說明，不給出分數。

規則公開

本文字、計分規則及變更記錄全部公開，任何人均可提出意見。

3五個部分，15 項指標

每個部分針對品牌提出一個問題；每項指標依據其下所列核查項評定（共 73 項核查）。點選指標可檢視核查項。

A

可識別性與信息一致性

你是誰，外部能否確認，不同來源能否對得上？
A1主體可核驗事實核查 · 5 項核查

得分 = 5 × 達標核查項所佔比例。

  1. A1.1
    官網及官方渠道列明品牌背後的公司（法律實體）。
  2. A1.2
    我們列明該公司的註冊國家或地區。
  3. A1.3
    任何人都可以在政府企業登記或其他官方記錄中查到該公司。關鍵項
  4. A1.4
    外界清楚知道品牌由哪家公司擁有或經營。
  5. A1.5
    我們公佈與該公司相符的業務地址或聯絡方式。
A2關鍵經營與責任信息清晰事實核查 · 5 項核查

得分 = 5 × 達標核查項所佔比例。

  1. A2.1
    我們公開列出管理層、創辦人或主要負責人。
  2. A2.2
    我們在 LinkedIn 或類似專業平台設有公司專頁。
  3. A2.3
    主要管理人員（包括海外市場負責人）有可供查核的公開職業資料。
  4. A2.4
    我們公佈有效的客戶、業務及媒體聯絡渠道。
  5. A2.5
    在重要海外市場，外界能找到當地負責的公司、團隊或聯絡人。
A3跨渠道信息一致性與有效性事實核查 · 4 項核查

得分 = 5 × 達標核查項所佔比例。

  1. A3.1
    我們的名稱、公司、所在地及主營業務，在官網、企業登記及主要平台上一致。
  2. A3.2
    官網各語言版本在核心事實上一致。
  3. A3.3
    我們的 LinkedIn 等專頁與官網及登記資料一致。
  4. A3.4
    我們的核心公司資料是最新的。
B

外部評價與履約口碑

真實的客戶和夥伴關係留下了什麼記錄？
B1消費者反饋外部記錄 · 5 項核查

得分 = 記錄整體表現（1–5）與「5 × 達標核查項比例」的平均值。須有足夠記錄方可評定。

  1. B1.1
    可以找到並追溯有關我們的客戶評分、評價或投訴記錄。
  2. B1.2
    我們在所屬市場的主要評價、電商或投訴平台上有真實記錄。
  3. B1.3
    可以看到這些評價的數量、日期及分佈。
  4. B1.4
    同類投訴或負面體驗在不同記錄中反覆出現。
  5. B1.5
    投訴及爭議顯示為已解決、已結案或跟進中。
B2商業夥伴履約與合作記錄外部記錄 · 5 項核查

得分 = 記錄整體表現（1–5）與「5 × 達標核查項比例」的平均值。須有足夠記錄方可評定。

  1. B2.1
    我們與客戶、供應商或買家的業務關係可以獨立核實。
  2. B2.2
    有重複訂單、多年合作或長期項目的記錄。
  3. B2.3
    我們提及的主要客戶、項目或夥伴，可由對方或其他來源確認。
  4. B2.4
    有關我們的第三方信用或付款記錄存在。
  5. B2.5
    存在已確認的重要履約爭議、長期拖欠、重大違約或合作中斷記錄。
B3其他真實外部體驗信號外部記錄 · 5 項核查

得分 = 記錄整體表現（1–5）與「5 × 達標核查項比例」的平均值。須有足夠記錄方可評定。

  1. B3.1
    員工、專業用戶或其他持份者留下了可追溯的反饋。
  2. B3.2
    可以確認這些反饋的來源、日期及背景。
  3. B3.3
    相關平台會核實交易或身份。
  4. B3.4
    相同體驗或問題在多個記錄中反覆出現。
  5. B3.5
    不同主要外部來源之間存在明顯且未解釋的衝突。
C

合規與治理

規則要求是否滿足，是否存在重大風險？
C1市場准入與必要資質事實核查 · 5 項核查

得分 = 5 × 達標核查項所佔比例。

  1. C1.1
    我們已取得在目標市場經營所需的牌照、登記或認證。關鍵項
  2. C1.2
    這些資質目前有效。
  3. C1.3
    可在官方數據庫（監管機構、發證機構等）查核。
  4. C1.4
    存在已確認的關鍵資質到期、撤銷、失效或適用範圍重大變化。
  5. C1.5
    仍在使用已失效、被撤銷或與適用範圍不符的資質信息。
C2關鍵合規與治理基礎成熟度等級 · 8 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。

  1. C2.1
    公司有與規模及風險相稱的合規負責人或安排。
  2. C2.2
    我們設有商業操守、反賄賂、反欺詐或舉報機制。
  3. C2.3
    我們設有私隱及數據保護政策，並有專人負責。
  4. C2.4
    我們能證明擁有或有權使用主要品牌、產品及技術。
  5. C2.5
    有關產品性能、健康、安全或環保的宣稱有證據支持。
  6. C2.6
    我們就勞工及供應鏈規定設有政策或管理制度。
  7. C2.7
    我們設有制裁及出口管制篩查。
  8. C2.8
    我們符合其他適用的合規要求，並能提供證明。
C3法律、監管與治理記錄記錄等級 · 六級量表

按記錄等級評定：選擇與該機構法律、監管及治理記錄相符的等級。

  1. 5
    沒有法律或監管問題. 已查閱法院、監管機構及公司登記記錄，未發現重要問題。
  2. 4
    僅有過往問題，均已解決. 過往的案件、罰款或監管結論均已結案或整改，且沒有再發生。
  3. 3
    有一般事項仍在處理. 例如商業糾紛或監管機構的問詢，目前正在處理。
  4. 2
    有已確認的問題，正在整改. 例如被罰款或被認定違規，整改正在進行。
  5. 1
    已確認的問題反覆出現或仍未解決. 同類問題多次發生，或至今仍未整改。
  6. 0
    有嚴重違規. 例如重大處罰、牌照被吊銷或刑事認定。
D

透明度與響應

需要答案時，企業如何說明和行動？
D1必要信息披露成熟度等級 · 5 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。

  1. D1.1
    客戶、夥伴、員工等可以輕易找到判斷我們所需的資料。
  2. D1.2
    我們作出重要事實陳述時，會說明數據來源或計算方法。
  3. D1.3
    我們清楚區分已確認的事實、預測及觀點。
  4. D1.4
    重要公開資料有變時，我們會更新或更正。
  5. D1.5
    發生重大事項時，我們會在法律許可範圍內向相關人士說明已確認的事實。
D2投訴與爭議響應成熟度等級 · 6 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。 若評估期內未發生投訴、糾紛或重大事件，得分上限為 3：既有機制尚未經實際檢驗。

  1. D2.1
    我們設有清晰的投訴、爭議或重大事項處理渠道。
  2. D2.2
    公司內有專人負責回應，並有基本流程。
  3. D2.3
    有個案出現時，我們作出了回應。
  4. D2.4
    可以證明我們何時及如何回應。
  5. D2.5
    我們的回應說明目前已確認的事實，並在需要時附上證據。
  6. D2.6
    我們的回應列出修正、補救或整改方案，以及負責人。
D3整改與後續行動成熟度等級 · 5 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。 若評估期內未發生投訴、糾紛或重大事件，得分上限為 3：既有機制尚未經實際檢驗。

  1. D3.1
    我們公佈的修正或措施已實際執行。
  2. D3.2
    這些措施產生了可核實的結果（如結案、賠償、完成回收、發佈修正或修改政策）。
  3. D3.3
    對仍在處理的事項，我們會發佈跟進更新。
  4. D3.4
    公司以外的來源可證實這些措施或結果。
  5. D3.5
    後續經營中再次出現同類問題。
E

責任實踐與本地化

長期經營留下了什麼本地記錄？
E1可驗證責任實踐成熟度等級 · 5 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。

  1. E1.1
    我們有與業務及當地經營相關的責任實踐（ESG/CSR）、目標或項目。
  2. E1.2
    我們已把承諾付諸行動，而不只是政策或宣傳。
  3. E1.3
    這些行動持續進行。
  4. E1.4
    這些行動有可核實的成果或進度記錄。
  5. E1.5
    有第三方夥伴、認證或鑒證支持。
E2本地僱傭與合作成熟度等級 · 5 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。

  1. E2.1
    我們在海外市場聘用當地員工。
  2. E2.2
    我們投資培訓及發展當地人才。
  3. E2.3
    我們與當地業務夥伴或供應商合作。
  4. E2.4
    當地招聘及合作持續進行。
  5. E2.5
    公司以外的記錄可證實以上情況。
E3社區與長期本地關係成熟度等級 · 5 項核查

得分 = 成熟度等級（0–5），並受達標核查項比例限制。

  1. E3.1
    我們參與當地社區、行業組織或其他本地活動。
  2. E3.2
    我們持續參與，而不只是一次性活動。
  3. E3.3
    這已建立外界可見的長期關係。
  4. E3.4
    這對當地經營或社區關係帶來可見的成果。
  5. E3.5
    當地夥伴、行業組織、社區團體或其他記錄可證實。

關鍵項：關鍵核查項未達標時，該指標最高為 1 分。A、C 兩部分各有一項關鍵指標（A1 和 C1）。

4指標如何評定

每項核查的回答為「是」「否」「不確定」或「不適用」；不適用的專案不計入。隨後每項指標得到 0 至 5 的評級，或 ND（資訊不足）。

型別指標0–5 評級如何得出
事實核查A1, A2, A3, C15 × 已回答核查項中達標項的比例，四捨五入。至少須回答 60% 的核查項，否則為 ND。
外部記錄B1, B2, B3取兩者的平均值：記錄顯示的整體表現（1–5），以及 5 × 達標核查項比例。記錄過少、不足以判斷時為 ND。
成熟度等級C2, D1, D2, D3, E1, E2, E3成熟度等級（0–5，見下表），並受核查項支援程度的限制。
記錄等級C3在六級記錄量表（0–5）中選取相符的等級。
成熟度等級含義
0 · 未建立確認未建立，或實際做法與要求相反。
1 · 初始／零散已有零散行動或承諾，但未形成穩定責任和機制。
2 · 基礎建立已形成責任主體、制度或流程，但實際運行有限。
3 · 穩定運行已規律進入實際經營，並形成持續記錄。

5 · 成熟嵌入已成為日常經營的一部分，並有跨期、可核驗的記錄。

5計分規則

  • 部分評級（0–5）。 取該部分已評定指標的平均值，精確到 0.5。每個部分至少須有 2 項已評定指標，且關鍵指標必須已評定，否則為 ND。
  • 短板會限制部分評級。 任何一項指標為 0，或關鍵指標為 0–1 時，該部分最高為 3。
  • 總分（0–100）。 20 × 五個部分評級的平均值。
  • 重大風險會限制總分。 存在尚未解決的重大風險，或 A1、C1 評級為 0–1 時，總分上限為 59；A 或 C 部分評級為 0–1 時，上限為 39。
  • 資訊不足。 A 或 C 部分無法評定、已評定部分少於 4 個，或已回答專案不足 60% 時，不給出總分。
  • 證據支援度。 隨每個結果一併報告。高：已回答專案不少於 80%，且不少於 50% 經獨立來源核實。中：已回答不少於 60%。低：不少於 40%。
  • 取整。 所有取整均採用整數運算的四捨五入，結果不因計算裝置而異。
0–19基礎不足
20–39初步建立
40–59基本建立
60–79較為穩定
80–100穩定成熟

6結果如何使用

用途證據由誰提供公開內容
會員自測 測試版會員就其已透過徽章確認的自有品牌回答核查項。官網掃描可為「不確定」的專案補充確認，但絕不會拉低分數。不公開。結果僅供參考，僅會員本人及秘書處可見。
信任評審 尚未開放由品信會核查每項指標背後的證據。將隨進階會籍開放，時間在第 1 版釋出並完成有獨立專家評審的測試期之後。達到已公佈標準的品牌：在登記冊中顯示 Verified Trusted 等級、總分及各部分概況。目前尚未簽發。

Verified Trusted 等級的具體要求將隨第 1 版公佈。 如何檢視登記記錄 →
