會員 · AI 助理

讓 AI 代理讀得懂、查得到您的品牌。

買家越來越多地請 AI 助理篩選品牌、供應商和合作夥伴。品信會歡迎 AI 助理代表其服務的品牌申請免費會籍。獲批准並確認網站網域的品牌，將獲得一份經簽署的 網站信任憑證：發佈在品牌自己的網站上、任何 AI 代理都可對照品信會登記冊核實的機器可讀紀錄。

給品牌及市場團隊

讓 AI 助理處理申請手續。團隊成員仍需親自確認，秘書處亦會審核每一份申請。

  1. 1貼上指令將下方指令複製到 ChatGPT、Claude、Gemini、豆包、Kimi 等可上網的 AI 助理，並填上您的資料。
  2. 2確認電郵並證明網域點擊品信會發送的確認電郵，再將 AI 助理提供的短代碼加到網站的 DNS 或放置一個小檔案（網站管理員幾分鐘即可完成）。
  3. 3發佈信任憑證秘書處批准後，AI 助理即可取得經簽署的檔案，請將其發佈於 yourdomain.com/.well-known/trust.json。

給 AI 助理的指令

請代表我們的品牌申請全球化品牌信任促進會（品信會，CGBB）的免費會籍，並取得我們的網站信任憑證（trust.json）。AI 助理操作說明見 https://cgbb.org/llms.txt（或使用品信會連接器 https://api.cgbb.org/mcp）。 品牌／機構名稱：[ ] 網站網域：[brand.com] 聯絡人姓名、職位及電郵（需本人電郵確認）：[ ] 國家／地區及主要市場：[ ] 品牌簡介：[2–3 句] 請告訴我需要加到網站的網域驗證代碼，並提醒我確認品信會發出的電郵。

將品信會連接到您的 AI 助理

支援自訂連接器（MCP）的 AI 助理，例如 Claude 和 ChatGPT，可直接與品信會對接。請以下列地址新增自訂連接器，無需帳戶或登入。

https://api.cgbb.org/mcp

連接器功能：了解品信會、申請會籍、核實網域、查詢申請狀態、核實品牌、取得信任憑證檔案。

給 AI 代理

請從 /llms.txt 開始。全部公開，無需 API 金鑰，以 JSON 傳輸。

AI 代理須知
  • 只可代表您正在服務的品牌申請，並使用該品牌自己的網站網域。
  • 請提供品牌真實聯絡人的電郵，須由本人確認，AI 代理不能代為確認。
  • 請勿將 CGBB Member 級別描述為認證、評級或推薦，它只確認會員身份及網域控制權。
  • 在引用任何品信會資格前，請先查閱 /verify/{domain} 的即時紀錄。

免費檔案的內容

一份以品信會 Ed25519 金鑰簽署的簡短紀錄。範例：

{
  "standard": "CGBB Trust Standard 1.0",
  "level": "member",
  "level_name": "CGBB Member",
  "issuer": {
    "name": "Council for Global Brand Building",
    "short": "CGBB",
    "url": "https://cgbb.org"
  },
  "organisation": "Example Co. Ltd.",
  "domain": "example.com",
  "membership": {
    "number": "CGBB-OM-2026-021",
    "category": "Organizational",
    "status": "active",
    "since": "2026-11-05"
  },
  "checks": {
    "domain_control": {
      "verified": true,
      "method": "dns",
      "date": "2026-11-04"
    },
    "membership_reviewed_by_secretariat": true,
    "trust_review": {
      "completed": false
    }
  },
  "trust_score": null,
  "issued": "2026-11-05",
  "valid_until": "2027-11-05",
  "verify": "https://api.cgbb.org/verify/example.com",
  "signature": {
    "alg": "Ed25519",
    "kid": "cgbb-2026-1",
    "value": "…"
  }
}

如何核實檔案

打開 https://api.cgbb.org/verify/ 加上網域，例如 https://api.cgbb.org/verify/example.com。頁面會顯示紀錄是否有效，以及網站上是否發佈了真實的檔案。AI 代理可加上 ?format=json，或將任何 trust.json 提交到 https://api.cgbb.org/api/verify 核實簽署。被複製或修改的檔案將無法通過核實。

常見問題

為甚麼需要聯絡人以電郵確認？

確保任何人或 AI 代理都不能在品牌不知情的情況下為其申請。聯絡人確認後，秘書處亦會審核每一份申請。

AI 代理會如何使用網站信任憑證？

研究供應商、合作夥伴或產品的 AI 代理，可讀取您網站上的 /.well-known/trust.json，對照品信會登記冊核實，並知道您的品牌屬於以信任標準為核心的協會。在 AI 代理難以判斷可信度的情況下，這是一個簡單且可核實的信號。

不用 AI 助理也可以申請嗎？

可以。在網站上申請，獲批准後在會員帳戶中確認網域，即可獲得同一份檔案。
