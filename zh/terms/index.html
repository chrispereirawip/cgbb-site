CGBB

使用條款

最後更新：2026年11月6日

本條款適用於 cgbb.org、api.cgbb.org、品信會會籍、品信會網站信任憑證，以及供 AI 代理使用的品信會連接器及 API（api.cgbb.org/mcp）。條款由全球化品牌信任促進會（「品信會」、「我們」，於香港成立的非牟利協會）制定。使用上述服務即表示您接受本條款。查詢：secretariat@cgbb.org。

會籍

  • 品信會基本會籍免費。秘書處審核每一份申請，並可批准、拒絕、暫停或終止會籍，例如所提供資料不準確或會員違反本條款。
  • 申請人須提供準確資料，只可為其代表的機構申請，並使用該機構自己的網站網域，以及同意接受聯絡的真實人員的工作電郵。
  • 進階會員為付費服務。價格、收費及續期方式會在購買前列明；會籍每年自動續期，直至取消，您可隨時取消續期。

網站信任憑證

  • 免費的品信會網站信任憑證（CGBB Member 級別，以 trust.json 檔案發佈）確認該機構是獲批准的品信會會員、控制所列網站網域，並有已透過電郵確認的聯絡人。
  • 它並非對機構或其產品、服務或行為的認證、評級、背書或保證。信任評分及 CGBB Verified Trusted 級別只隨付費的全面信任評審提供。
  • 憑證只可發佈於其所屬網域。api.cgbb.org/verify 的即時紀錄具最終效力；品信會可暫停或撤銷憑證，被撤銷的憑證須予移除。
  • 不得修改憑證檔案，或誇大其含義。複製或修改過的檔案無法通過核實。

AI 代理、連接器及 API

  • 品信會連接器（api.cgbb.org/mcp）及 API 可免費使用，無需 API 金鑰，惟須合理使用並受流量限制。
  • AI 代理只可在用戶知情下，為用戶所代表的品牌申請。代理不能代人確認申請，須由聯絡人以電郵確認。
  • 不得利用服務發送垃圾訊息、提交虛假或大量申請、探測或令系統超載，或收集其他會員公開核實紀錄以外的資料。
  • 我們可隨時更改、限制或暫停連接器或 API，或封鎖濫用行為。

名稱、標誌及徽章

  • 品信會、CGBB、品信會標誌及「信任已核實」徽章屬品信會所有。會員可如實提及其會籍；「信任已核實」徽章只可由持有該級別的機構展示，並須連結至其即時紀錄。

基線自測及其他內容

  • 免費基線自測僅供初步參考，並非正式評估、認證或專業意見。cgbb.org 上的內容僅供一般參考。

不作保證及責任

  • 服務按「現狀」提供。我們不保證服務不會中斷或沒有錯誤，亦不保證任何搜尋引擎或 AI 系統如何排序、引用或看待任何機構。
  • 在法律允許的範圍內，品信會不就使用服務引致的間接或相應損失負責。本條款不限制法律不容許限制的責任。

私隱

  • 我們如何處理個人資料，請參閱私隱政策。

修訂及適用法律

  • 我們可更新本條款，並會在本頁公佈修訂及更新日期。本條款受香港特別行政區法律管轄。
