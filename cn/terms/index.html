CGBB

使用条款

最后更新：2026年11月6日

本条款适用于 cgbb.org、api.cgbb.org、品信会会籍、品信会网站信任凭证，以及供 AI 代理使用的品信会连接器及 API（api.cgbb.org/mcp）。条款由全球化品牌信任促进会（“品信会”、“我们”，于香港成立的非营利协会）制定。使用上述服务即表示您接受本条款。查询：secretariat@cgbb.org。

会籍

  • 品信会基本会籍免费。秘书处审核每一份申请，并可批准、拒绝、暂停或终止会籍，例如所提供资料不准确或会员违反本条款。
  • 申请人须提供准确资料，只可为其代表的机构申请，并使用该机构自己的网站域名，以及同意接受联系的真实人员的工作邮箱。
  • 进阶会员为付费服务。价格、收费及续期方式会在购买前列明；会籍每年自动续期，直至取消，您可随时取消续期。

网站信任凭证

  • 免费的品信会网站信任凭证（CGBB Member 级别，以 trust.json 文件发布）确认该机构是获批准的品信会会员、控制所列网站域名，并有已通过邮件确认的联系人。
  • 它并非对机构或其产品、服务或行为的认证、评级、背书或保证。信任评分及 CGBB Verified Trusted 级别只随付费的全面信任评审提供。
  • 凭证只可发布于其所属域名。api.cgbb.org/verify 的即时记录具最终效力；品信会可暂停或撤销凭证，被撤销的凭证须予移除。
  • 不得修改凭证文件，或夸大其含义。复制或修改过的文件无法通过核实。

AI 代理、连接器及 API

  • 品信会连接器（api.cgbb.org/mcp）及 API 可免费使用，无需 API 金钥，惟须合理使用并受流量限制。
  • AI 代理只可在用户知情下，为用户所代表的品牌申请。代理不能代人确认申请，须由联系人以邮件确认。
  • 不得利用服务发送垃圾信息、提交虚假或大量申请、探测或令系统超载，或收集其他会员公开核实记录以外的资料。
  • 我们可随时更改、限制或暂停连接器或 API，或封锁滥用行为。

名称、标志及徽章

  • 品信会、CGBB、品信会标志及“信任已核实”徽章属品信会所有。会员可如实提及其会籍；“信任已核实”徽章只可由持有该级别的机构展示，并须链接至其即时记录。

基线自测及其他内容

  • 免费基线自测仅供初步参考，并非正式评估、认证或专业意见。cgbb.org 上的内容仅供一般参考。

不作保证及责任

  • 服务按“现状”提供。我们不保证服务不会中断或没有错误，亦不保证任何搜寻引擎或 AI 系统如何排序、引用或看待任何机构。
  • 在法律允许的范围内，品信会不就使用服务引致的间接或相应损失负责。本条款不限制法律不容许限制的责任。

私隐

  • 我们如何处理个人资料，请参阅隐私政策。

修订及适用法律

  • 我们可更新本条款，并会在本页公布修订及更新日期。本条款受香港特别行政区法律管辖。
