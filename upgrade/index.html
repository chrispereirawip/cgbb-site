Show people, and the AI agents working for them, that your brand can be trusted.

  1. 1Upgrade your membershipAdvanced membership is taken for a minimum of one year.

The file stays valid while the membership is active and the brand remains at or above 80% at its annual review.

FAQ

Can someone copy our trust.json and put it on their own website?

They can copy the file, because it is public by design, but a copy is worthless. Each file is locked to the exact domain it was issued for, so a copy on another website fails the check immediately.

Can the score or dates in the file be changed?

No. CGBB digitally signs every file with a private key that only CGBB holds, and publishes the matching public key on cgbb.org. Changing a single character, such as the score or the expiry date, breaks the signature.

How do AI agents and buyers know a file is genuine?

Every file links to its record at api.cgbb.org. Agents check that live record directly, so the CGBB registry, not the file itself, is the final word on whether a brand is verified today.

What happens if a brand’s membership lapses or its score falls?

CGBB withdraws the record in the registry. The file on the brand’s website then fails verification, even though it still looks unchanged. Files also expire after a set period and are renewed after each annual review.

What if a website shows the badge or file without being verified?

Anyone can look the domain up in the public CGBB registry. A brand that claims to be verified but has no live record is exposed by that check, and CGBB may act against misuse of its marks.

Does upgrading guarantee a trust.json file?

No. The file is only issued to organisations that hold an active Advanced membership and score at least 80% on the comprehensive Trust Review.
