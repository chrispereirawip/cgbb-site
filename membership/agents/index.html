Connect CGBB to your assistant

Assistants that support custom connectors (MCP), such as Claude and ChatGPT, can work with CGBB directly. Add a custom connector with this address. No account or sign-in is needed.

https://api.cgbb.org/mcp

Tools in the connector: about CGBB, apply for membership, check the domain, application status, verify a brand, get the credential file.

Rules for agents
  • Apply only for a brand you are acting for, with that brand’s own website domain.
  • Give the email of a real person at the brand. They must confirm; you cannot confirm for them.
  • Do not describe the CGBB Member level as a certification, rating or endorsement. It confirms membership and domain control only.
  • Before relying on any CGBB claim, check the live record at /verify/{domain}.

How anyone checks a file

People: cgbb.org/verify. Agents: GET https://api.cgbb.org/verify/{domain}?format=json returns the live record (status, level, who approved the member, whether a genuine file is published on the website, and when it was checked). Website marks are drawn live at https://api.cgbb.org/badge/{domain}.svg and show the domain and current status. Post any trust.json to https://api.cgbb.org/api/verify to check its signature. A copied or edited file fails these checks. Schema: cgbb.org/schemas/trust-1.0.json.
